## 1. Introdução

Esta página reúne o material **HTA do Redesign – Renovação guiada da CNH**, elaborado por Gabriel Robson na Entrega 5 do projeto do Grupo 03 sobre o Portal do Detran-DF. O conteúdo está organizado em: objetivo 0; limitações.

## 2. Objetivo 0

**Organizar a renovação da CNH com orientação guiada e, quando aplicável, solicitação simulada de agendamento.**

O conteúdo a seguir está organizado na Tabela 3.

**Tabela 3 – Objetivo 0**

| Tarefa | Subtarefas propostas |
| --- | --- |
| 1. Iniciar renovação | 1.1 Acessar “Renova CNH Fácil”; 1.2 ler informação de que é protótipo acadêmico |
| 2. Informar situação | 2.1 Selecionar tipo de necessidade; 2.2 identificar se há condição que requer informação complementar |
| 3. Consultar etapas | 3.1 Exibir orientações; 3.2 verificar documentos; 3.3 identificar atendimento ou exame, se pertinente |
| 4. Simular agendamento, se cabível | 4.1 Selecionar tipo de local; 4.2 selecionar data; 4.3 selecionar turno; 4.4 conferir resumo |
| 5. Concluir simulação | 5.1 Confirmar escolhas; 5.2 receber resumo demonstrativo; 5.3 acessar orientação para canal oficial |

Fonte: elaborado pelo autor (2026).

**Plano 0:** executar 1 → 2 → 3; se a situação demandar atendimento a agendar, executar 4 → 5. Caso contrário, executar apenas a orientação oficial. **Plano 4:** executar 4.1 → 4.2 → 4.3 → 4.4 e permitir voltar para corrigir dados.

**Critério de sucesso para o protótipo:** usuário identifica que é uma simulação, compreende as etapas, consegue escolher opções e encontra orientação para o canal oficial.

**Limitação:** nenhum local nem horário do protótipo representa disponibilidade real. Não há integração com Gov.br ou com o Detran-DF.

## 3. Limitações

**Nota metodológica:** esta é uma proposta acadêmica, não é serviço oficial e não confirma que as etapas, taxas, regras ou agendamentos correspondam ao procedimento vigente do Detran-DF. Não foram realizados testes nem entrevistas para esta proposta.
